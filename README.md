# 🐝 Madhu-Siri (Bee-Farmer Harmony App)

## Android App Development using GenAI – Agriculture Project

Madhu-Siri is a smart Android application developed to improve communication between **Beekeepers** and **Farmers**. The main goal of this project is to protect bees from harmful pesticide spraying by allowing farmers to notify nearby beekeepers before spraying activities.

This project supports:

* Sustainable Agriculture 🌱
* Bee Protection 🐝
* Better Crop Pollination 🌾
* Improved Honey Production 🍯

---

## 📌 Problem Statement

Beekeeping (Apiculture) is a valuable side-income for many people, but bees are dying due to pesticide spraying in nearby fields.

### Current Problems:

* Farmers spray pesticides without knowing nearby hive locations
* Beekeepers do not receive prior warnings
* Bee colonies get damaged during active foraging hours
* Crop pollination and honey production decrease

### Proposed Solution:

Madhu-Siri helps by:

* Allowing beekeepers to pin hive locations
* Helping farmers view nearby bee hives
* Sending real-time spray alerts before pesticide use
* Protecting bees through early notifications

## 🔥 Firebase Setup

1. Create Firebase Project
2. Connect Android App
3. Enable Authentication
4. Enable Realtime Database
5. Enable Firebase Cloud Messaging
6. Download `google-services.json`
7. Place file inside app folder

---

## 🗺 Google Maps Setup

1. Open Google Cloud Console
2. Enable Maps SDK for Android
3. Generate API Key
4. Add API key in `AndroidManifest.xml`
